# File Overview

Radio-style selectable card for display preference options (currency JOD/USD; measurement SQFT/SQM).

**Source:** `src/features/profile/components/DisplayPreferenceOptionCard.tsx`

# UI

- Selected: `border-primary`, `bg-primary-light/50`, primary text accents, filled `bg-primary` radio dot.
- Unselected: `border-secondary/15`, `bg-surface`.
- Icon box: **symbol** text (currency symbols or `ft²` / `m²` for measurement). Code + full name; light/dark themes.
